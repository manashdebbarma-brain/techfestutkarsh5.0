UTKARSH 5.0 — VERSION 12

This version keeps the V11 rulebook popup design and adds an easy-edit event configuration file.

EASY EDIT:
1. Open event-config.js.
2. Change title, rules, eligibility, judging, registration URL (url), or poster URL (poster).
3. Save the file.
4. Push/deploy the project again to Vercel.

The website does not need a backend for these edits. For production, replace draft rulebook text with committee-approved content before publishing.
